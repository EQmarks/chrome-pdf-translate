框选译 v1.0.0

网页框选即译；Chrome 内置 PDF 阅读器里选中文字后右键翻译，或 Ctrl+C 让译文自动出现在侧栏。

翻译

关掉后：只有内置 PDF 阅读器里框选才会自动翻译；网页里仍可以右键「翻译选中文字」，但不会再自动弹卡。

PDF 专项

    
    
    
Chrome 内置 PDF 阅读器是独立沙箱，网页脚本进不去，所以原生 PDF 里有两种方式：① 选中 → 右键「翻译选中文字」；② 选中 → Ctrl+C，译文自动进侧栏。

    
想要像网页一样「框选即译」：用内置 PDF 阅读器打开（右键 PDF 链接/页面 → 「用「框选译」阅读器打开」，或点扩展图标 → 用阅读器打开此 PDF，也可以把 PDF 直接拖进阅读器）。

    
侧栏

  


  

    
怎么用

    
    
      
  • 网页：鼠标框选任意文字，译文卡片在选区下方弹出；Esc 关闭，卡片可拖动、可复制、可朗读。
    • 
      
  • PDF：右键菜单「翻译选中文字」，或选中后 Ctrl+C，译文进入侧栏（扩展图标会亮起「译」）。
    • 
      
  • 只想选中不翻译：把触发方式改成「按住 Ctrl 才译」，或临时关掉划词翻译。
    • 
      
  • 隐私：只把你选中的文字发给翻译服务，不做任何后台采集；剪贴板监听只在本机读、只用于翻译刚复制的内容。
    • 
    

  


  

    
重置

    
  


  
设置即时生效，无需重启浏览器。
